TO PUT IT ONLINE:

2. The main file must be named index.html.
3. For a custom domain, connect the domain to your hosting.
4. After the site is online, request indexing in Google Search Console.

For a simple free option, you can use GitHub Pages. Create a repository, upload
index.html and all JPG files, enable Pages, and use the generated Pages address.
